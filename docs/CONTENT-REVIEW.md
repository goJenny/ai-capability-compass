# 초안 콘텐츠 검토

사용자의 승인에 따라 문항과 직무를 새로 작성한 초안입니다. 이전 대화에서 확인한 점수 분리·루브릭·안전·파일럿 원칙을 반영했습니다. 이전 v0.4 문항 전문의 복제본이나 검증된 GLAT/MAILS 도구가 아닙니다.

## 현재 구성

- SELF01–08: 과업 선택, 요청 구체화, 반복 개선, 근거 확인, 정보 보호, 성과 판단, 자동화 통제, 협업·공유.
- KNOW01–12: 생성 원리, 환각·검증, 과업 적합성, 프롬프트, 맥락 한계, RAG, 개인정보, 편향, 평가, 에이전트, 인젝션, 운영 통제.
- S1: 가상 VOC 6건을 근거로 의사결정 메모 작성.
- S2: 직무 7종별 자료 기반 활용·검증 과제.
- S3: 직무 7종별 승인·도구·실패 대응 에이전트 설계/구현 증거.

## 확정 전 검토

1. 구성개념과 문항의 대응, SELF 행동 척도 해석, KNOW 문항의 명확성·난이도·정답 타당성.
2. 직무 분류와 시나리오의 대표성, 제공 자료의 충분성, 완료 시간.
3. 실무 항목·가중치·0~4단계 기준의 구분 가능성, 평가자 간 일치도.
4. 설계형과 실구현형의 서로 다른 증거 기준, 구현 재현성 확인 방법.
5. 중대 결함 정의·심각도 판단·검토 담당자·복구와 판정 절차.
6. 파일럿 표본과 사용 목적, 점수 분포·신뢰도·타당도, 공정성·접근성.
7. USE 평균 규칙과 SELF 환산의 적절성. 파일럿 근거 없이 수준 구간·합격선 확정 금지.

## 원문 확정 또는 수정

`src/data.js`에서 문항, 직무, 시나리오와 루브릭을 수정합니다. `contentVersion`과 저장 키를 함께 새 버전으로 바꾸세요. 문항 수·척도·가중치 또는 집계 정책을 변경하면 `domain.js`, 테스트, 안내문, 데이터 모델도 함께 변경해야 합니다. 문항 버전 간 응답은 자동 합산하거나 비교하지 않습니다.
