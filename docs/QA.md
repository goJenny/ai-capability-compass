# 검증 기록

검증일: 2026-10-13 (KST). Windows / Node.js / Codex 앱 내 Chromium 브라우저.

## 자동 검증

`npm run check`: JavaScript 파일 5개 구문과 HTML에서 참조한 로컬 파일 존재 확인.

`npm test`: 19개 테스트 통과.

- SELF8·KNOW12·직무7, ID, 선택지·정답·루브릭 범위.
- KNOW의 12개 동일 배점 및 전체 제출 조건.
- SELF 보조지표, 미응답 null과 유효한 0점 구분.
- 0~4단계의 점수 계산, 누락·범위 밖·비정수 거부.
- USE의 S1/S2 완료 조건, BUILD 독립 점수, 총점 미산출.
- 직무7·설계형/실구현형 응답 저장 분리.
- 100점이어도 중대 결함 보고 시 판정 보류, 미제출 결함도 반영.
- 미확인·미충족·자기보고 충족의 안전 상태 구분.
- 작업 기록·루브릭·안전 확인·결함 메모의 제출 조건.
- 백업 왕복, 버전·유형·값·길이 검증, 임의 점수·verified 주장 제거.
- JSON 리포트의 검증 전 상태와 한계 고지.
- 활성 직무·유형의 진행률.
- 데모 평가기의 네트워크 미호출, 텍스트 길이로 점수를 추정하지 않음.
- 서버 응답 총점·verified 주장의 무시 및 로컬 재계산.
- 같은 출처 요청 제한, 서버 오류·JSON·버전·단계 검증.

## 브라우저에서 확인한 동작

- HTTP 첫 화면 200 응답, 화면·문항 렌더링, JavaScript 오류 없음.
- SELF 미응답 이동 차단 후 8개 응답 완료.
- KNOW 미응답 제출 차단, 12개 응답·채점·해설, 100점 정답 일치율.
- 새로고침 후 이름·SELF·KNOW 응답과 완료 상태 복원.
- S1 필수 입력 누락 안내, 작업 기록·루브릭·안전 응답 후 75점 자기채점.
- 제출한 S1 답안 수정 시 기존 점수와 완료 상태 즉시 무효화.
- S1 중대 결함 보고 시 리포트에 적격 판정 보류 표시.
- S2 100점·S3 설계형 50점 제출, USE 87.5 / BUILD 50 / KNOW 100 독립 표시 및 100% 진행률.
- JSON 파일 가져오기 확인·적용, 가져온 이름·응답 반영. HTML처럼 보이는 입력은 텍스트로만 표시.
- 시연용 예시 리포트 KNOW75 / USE60 / BUILD60, 모든 화면의 예시 배너.
- 직무를 IT·개발로 바꾸고 BUILD 실구현형 선택 시 코드·실행 증거 안내와 과제 변경.
- 1365px 데스크톱 화면, 390px 모바일 화면에서 문서의 가로 넘침 없음. 모바일 리포트 표는 개별 가로 스크롤.

## 검증 한계

- 앱 내 브라우저에서 다운로드 버튼의 처리와 안내, 오류 없는 실행은 확인했습니다. 다운로드 완료 이벤트와 실제 저장된 파일은 확인되지 않았습니다. 일반 브라우저에서 JSON/TXT가 실제 저장되는지 확인할 수 있습니다.
- 인쇄용 CSS를 포함했으나 실제 프린터/PDF 저장과 페이지별 레이아웃은 수동 확인이 필요합니다.
- `file://` 실행은 외부 모듈·fetch·의존성 없이 가능하도록 구성했지만, 이번 실시간 UI 검증은 HTTP 서버에서 수행했습니다. 브라우저별 로컬 파일 저장 정책은 다를 수 있습니다.
- 실제 LLM 백엔드·외부 API 호출, 코드 실행, 증거 진위, 인간 평가, 문항 타당도 검증은 제공·수행하지 않았습니다.

## 운영 전 수동 확인

1. Chrome/Edge 등 사용할 브라우저에서 ZIP을 풀어 `index.html` 또는 `npm start` 실행.
2. 진단 JSON·리포트 JSON·과제 TXT 다운로드 결과 열기.
3. 백업 가져오기로 원래 응답 복원, 버전이 다른 백업 거부 확인.
4. 인쇄/PDF 결과에서 검증 전 고지와 안전성 상태 유지 확인.
5. 실제 참여자·전문가와 문항·직무·루브릭·증거 기준 검토.
