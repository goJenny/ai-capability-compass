# AI Capability Compass v0.4 · Pilot

한국어 AI 역량진단 정적 프로토타입입니다. HTML/CSS/일반 JavaScript로 작성했으며 외부 패키지 설치, 빌드, API 키가 필요하지 않습니다.

**실무점수는 데모 자기채점이며 검증된 능력이 아닙니다.** 정답·문항·루브릭은 초안입니다. 전문가 검증 전에는 역량 인증, 인사평가, 선발 또는 적격 판정에 사용하지 않습니다.

## 실행

### 가장 간단한 실행

ZIP을 압축 해제하고 `index.html`을 브라우저에서 엽니다. 파일을 모두 같은 폴더 구조로 유지하세요. 외부 폰트·라이브러리·네트워크 호출 없이 작동합니다.

브라우저에 따라 `file://`의 저장 방식이 다를 수 있습니다. 응답을 보관하려면 **JSON 백업**을 내려받으세요. 파일 위치나 브라우저를 바꾸면 로컬 응답이 공유되지 않습니다.

### 로컬 서버 실행 — 권장

Node.js 20 이상이 설치된 환경에서 이 폴더를 열고 실행합니다. `npm install`은 필요하지 않습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 종료는 `Ctrl+C`입니다. 같은 주소·브라우저의 localStorage에 자동저장되며 서버에는 응답이 전송되지 않습니다. 포트가 사용 중이면 PowerShell에서 다음처럼 실행합니다.

```powershell
$env:PORT = '4174'
npm start
```

## 둘러보기

1. 진단 시작에서 닉네임(선택), 직무, BUILD 유형을 선택합니다.
2. SELF 8문항에 최근 행동을 응답합니다.
3. KNOW 12문항을 선택하고 `12문항 완료·채점`으로 정답·해설을 확인합니다.
4. S1·S2·S3의 작업 기록, 5개 루브릭 단계, 안전 확인을 입력합니다.
5. 각 과제의 `데모 점수 계산`을 눌러 제출합니다.
6. 결과 리포트에서 독립 점수, 안전 상태, 학습 참고 내용을 봅니다. 인쇄 화면에서 PDF 저장이 가능합니다.

빠른 확인은 `예시 결과 둘러보기`를 사용합니다. 현재 응답 교체 전 확인창이 나오며, 모든 화면과 출력에 시연용 데이터임을 표시합니다. 실제 진단은 `새 진단 시작`을 선택하세요.

## 포함 기능

- SELF 8문항 / KNOW 12문항 / 공통 S1
- 직무 7종별 S2·S3: 기획·전략, 마케팅·콘텐츠, 영업·고객지원, 인사·교육, 재무·회계, 운영·행정, IT·개발
- BUILD 설계형·실구현형 안내와 서로 다른 0~4단계 루브릭
- 직무·유형별 응답 분리 보관, 진단 진행률, 새로고침 복원
- 작업 기록 수정 시 기존 실무점수 무효화
- 전체 진단 JSON 내보내기·가져오기, 결과 JSON, 과제 안내 TXT
- 부분 리포트, 인쇄/PDF, 모바일 대응, 키보드 탐색, 안전 상태
- 데모 평가기와 같은 출처 서버 평가 어댑터 분리

## 문항 출처와 v0.4 적용 범위

이전 대화에서 아래 평가 원칙을 확인했습니다. 다만 이전 답변의 문항 전문·직무명·v0.4 전체 명세는 참조 표시로만 반환되어 회수되지 않았습니다. **사용자가 문항·직무 초안 제작을 승인해 새로 작성했습니다.** 이 패키지는 확정 문항의 정확한 복제본이 아닙니다. GLAT·MAILS 원문을 복제하거나 이 도구의 타당도를 계승했다고 주장하지 않습니다.

| 항목 | 구현 |
|---|---|
| KNOW / USE / BUILD 분리 | 세 점수 독립 표시, 전체 총점 없음 |
| SELF 보조지표 | 8문항 평균을 100점 환산, 역량점수에 합산하지 않음 |
| KNOW 동일 배점 | 12문항 각각 1점, 정답 수 ÷ 12 × 100 |
| S1·S2·S3 각 100점 | 각각 5개 항목, 0~4단계, 항목당 20% |
| Agent 유형 구분 | 설계형·실구현형 응답·안내·루브릭 분리, 직접 비교 없음 |
| 안전 필수조건 | 중대 결함 보고 시 적격 판정 보류·별도 검토 |
| 파일럿 | 등급·합격선 미산출, 문항과 점수의 검증 상태 표시 |
| 확장형 C | 기본 진단 → 직무 과제 → 유형별 BUILD로 진행 |

구현용 추가 초안 규칙: **USE = (S1 + S2) / 2**, 두 과제 모두 제출 시 산출. S3를 BUILD로 표시합니다. SELF는 0~4 행동 척도입니다. 각 실무과제의 동일 가중치와 실구현형 증거 요구는 전문가 검토 후 바꿀 수 있습니다.

미응답 점수는 `—`로 표시합니다. KNOW는 전체 제출 전, SELF는 8문항 응답 전 점수를 표시하지 않습니다. 실무점수는 전체 필수 항목과 루브릭을 입력하고 제출해야 표시합니다. 안전 상태는 미제출 상태에서도 응답을 바탕으로 표시합니다.

## GitHub 저장소에 올리기

새 저장소를 만든 뒤 이 폴더의 **내용**을 저장소 루트에 업로드합니다. `index.html`, `styles.css`, `src/`, `assets/` 경로를 유지하세요. 사용자 응답 백업이나 API 키를 업로드하지 마세요. `.gitignore`는 로컬 백업·비밀 설정·설치 파일을 제외합니다.

GitHub Pages로 제공하려면 저장소의 Pages 설정에서 업로드한 브랜치의 루트를 배포 원본으로 선택합니다. 정적 파일만으로 동작하며 하위 경로에서도 상대 경로와 해시 탐색을 사용합니다. 이 작업에서 GitHub 업로드나 공개 배포를 수행한 것은 아닙니다.

## 향후 LLM 연결

[API-CONTRACT.md](docs/API-CONTRACT.md)를 따라 서버의 `/api/evaluate`를 구현한 뒤 `src/evaluators.js`의 `Compass.evaluationConfig`를 서버 모드로 바꿉니다. 외부 LLM API 키는 서버의 환경변수로 보관합니다. 클라이언트에 키 입력창이나 외부 LLM 직접 호출은 없습니다.

LLM이 반환한 단계도 **미검증 평가 제안**입니다. 사람의 평가와 증거 검증, 보안 결함 검토, 평가자 식별, 문항·루브릭 버전 관리가 별도 구현되어야 합니다. 정적 페이지에서 `verified=true`를 받아 능력 인증으로 바꾸지 않습니다.

## 데이터와 한계

응답은 해당 브라우저·출처의 localStorage에 평문으로 저장됩니다. 여러 사용자 계정, 서버 저장, 암호화, 인증, 실제 코드 실행, 로그 검증, 파일 업로드는 구현하지 않았습니다. 데모에서 외부 AI를 쓴다면 사용자 스스로 민감정보를 제거한 자료만 사용하세요. 백업 JSON에는 모든 직무·유형의 응답과 작업 기록이 들어가므로 본인의 진단 데이터로 보관하세요.

정답은 브라우저 파일에 포함됩니다. KNOW는 공개된 초안 지식 문항의 정답 일치율이며 감독 시험을 위한 보안이 없습니다. 반복 응답은 해설 학습의 영향을 받을 수 있습니다. 안전 확인은 자기보고이며 자동 탐지나 안전 보증이 아닙니다.
